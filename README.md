# 菌络 / Mycelial Intelligence

> 没有大脑，也懂最优。

一个以多头绒泡菌（*Physarum polycephalum*）为灵感的实时交互网页。放置食物，种下菌核，观察一个没有神经系统的生命体如何用「身体」长出连接所有食物的近似最优脉络。

![首屏](preview/01-landing.png)

## 操作

1. 直接双击打开 `index.html`，或使用本地静态服务器访问。
2. 点击「开始实验」。
3. **左键**在画布上放置食物点，建议 3–6 处（最多 8 处）。
4. **右键**在任意空白处种下菌核，开始演化。触屏设备使用底部的「开始演化」按钮。
5. 观察信息素网络生长、食物节点逐个接入。
6. 网络收敛后查看最优脉络，可「保存图像」或「再次实验」。

推荐使用最新版 Chrome / Edge / Safari。页面不需要构建步骤，核心交互全部在浏览器本地运行。

## 算法

页面不是播放预录动画，每一次网络都由实时模拟生成。

### 1. 菌丝个体 / Physarum agents

画面中有 1,000 个左右的数字菌丝个体，每一帧只做三件事：

- 在前方、左前方、右前方三个方向采样信息素浓度；
- 将信息素方向与食物方向混合，朝更有利的方向转向并加入少量随机扰动；
- 在身后沉积信息素，并感知半径内尚未接入的食物。

食物节点被触达后会「孵化」新的菌丝个体，让网络继续向其余节点扩张。信息素场每步进行扩散和挥发，高频通道逐渐被强化，低效支路逐渐消失。

### 2. 最优脉络求解

演化结束后，对信息素场做一次多终端路径求解：

1. 计算每条网格边的通行代价：菌丝越浓，代价越低；
2. 从每个食物节点和菌核分别运行 Dijkstra，得到终端之间的测地距离与路径；
3. 在终端距离图上运行 Prim 最小生成树，连接所有食物；
4. 把生成树对应的网格路径做 RDP 简化与 Chaikin 平滑，绘制为最终脉络。

这相当于在演化出的信息素图上求一个近似最小 Steiner 网络。最终网络会吸附在菌丝轨迹上，而不是简单地用直线连接食物。

### 3. 视觉层

- 低分辨率信息素场负责体积感与呼吸般的柔光；
- 独立的高分辨率轨迹层记录每个个体的运动，形成细密、带轻微闪烁的生物脉络；
- 结果阶段将原始信息素降为背景，再逐段绘制高亮的最优网络，让节律粒子从菌核向外流动。

## 技术

- 原生 HTML / CSS / JavaScript，无框架、无构建流程；
- Canvas 2D：自定义 Physarum 智能体模拟、信息素扩散、Dijkstra + Prim 求解、粒子与描边动画；
- 支持鼠标与触屏；会预留底部结果面板空间，避免食物点被遮挡；
- 支持 `prefers-reduced-motion`；
- 「保存图像」使用 Canvas 重新排版导出 2800px 宽的结果档案图。

```
└─ README.md
```

## 运行方式

直接打开：

```
mycelium/index.html
```

或者起一个本地静态服务器：

```bash
cd mycelium
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

字体使用 Google Fonts 的 Noto Serif SC 与 Manrope，并以非阻塞方式加载；离线时会自动回退到系统中文字体与无衬线字体，页面功能不受影响。
